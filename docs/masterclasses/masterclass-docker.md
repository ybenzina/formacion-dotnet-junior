# Masterclass Docker / Contenedores

La clase de Docker forma parte de [cloud, sesión 1: contenedores, Compose y Aspire](masterclass-cloud-local.md). Se da como avance de unos 35 minutos **el domingo 22/11**, antes del ejercicio 4 de la Parte II (L 23/11); tus archivos se revisan en la demo 2 del 27/11. Aspire es un extra.

Un **Dockerfile** es una receta para construir una imagen de tu aplicación. **Multi-stage** significa que la receta separa la construcción y la ejecución: como cocinar en una cocina equipada y llevar a la mesa solo el plato terminado. **Compose** describe varios servicios que arrancan juntos, por ejemplo web, API y base de datos. Estos términos se repasan con ejemplos en la sesión 1.

La [sesión 2: Azure, infraestructura como código y costes](masterclass-cloud-azure.md) será **el domingo 29/11, a las 17:00**, antes del despliegue del Día 22.
