# Fase 2 — Temas pendientes

El plan original de la fase 2 tenía ocho semanas (7 a 14). Se ha sustituido por el **reto CourtConnect** de dos semanas (`Semana7/` y `Semana8/`). Estos temas quedan para más adelante, cuando el proyecto real los necesite o haya tiempo:

| Tema | Plan original | Notas |
|---|---|---|
| ADO.NET y Dapper | Semana 7 | Comparar con EF Core: cuándo compensa SQL a mano |
| Caché en memoria (`IMemoryCache`) | Semana 7 | Listados frecuentes |
| Tecnologías web heredadas: WebForms y jQuery/AJAX | Semana 8 | Solo para reconocerlas en sistemas antiguos |
| ASP.NET Core MVC | Semana 8 | UI en servidor con controladores y vistas |
| Componentes Blazor avanzados, `IOptions` | Semana 9 | El reto cubre lo básico de Blazor |
| Minimal APIs frente a controladores, gRPC | Semana 10 | El reto usa una de las dos opciones |
| Arquitectura: SOLID, Clean Architecture, Vertical Slice | Semana 11 | Ver `docs/masterclasses/masterclass-architecture.md` |
| Caché distribuida con Redis (`IDistributedCache`) | Semana 11 | Ver `docs/court-connect/architecture/refactor-getevent-redis.md` (borrador) |
| .NET MAUI y MAUI Blazor Hybrid | Semana 12 | Reutilizando los componentes Razor del reto |
| Observabilidad: Application Insights, Serilog | Semana 13 | |
| Seguridad: Identity, JWT | Semana 13 | |
| Despliegue en Azure (Container Apps, Azure SQL) | Semana 14 | Puede entrar como extra al final del reto |

Las carpetas `Semana9/` a `Semana14/` con los enunciados originales (eran plantillas sin desarrollar) se eliminaron del repositorio. Siguen en el historial de Git.
