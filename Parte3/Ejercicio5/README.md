# Ejercicio 5 — PR trampa y demo final

**Viernes 20 de noviembre · estimación: 4 h** · Issue: «P3 · Ej5 · PR trampa y demo final»

## Objetivo

Comprobar que sabes supervisar código generado y cerrar el reto.

## Pasos

### 1. PR trampa (≈ 1 h 30 min)

Yamel abre un PR generado con IA que contiene varios defectos sembrados. Revísalo en GitHub como revisor y comenta cada defecto que encuentres, **señalando la línea y explicando el riesgo**. No sabes cuántos hay.

### 2. Retro final (≈ 1 h)

En `docs/learning/retro.md`:

- Qué tecnologías del reto ya sabrías supervisar en un proyecto real y cuáles necesitan refuerzo.
- Conclusiones del piloto SDD para la decisión PD-11: ¿compensa?, ¿en qué tipo de funcionalidades?, ¿con qué herramienta?
- Qué harías distinto si empezaras el reto otra vez.

### 3. Demo final (≈ 1 h 30 min con la preparación)

Ver [`Parte3/README.md`](../README.md#demo-final).

## Criterios de aceptación

- [ ] PR trampa revisado, con cada defecto encontrado comentado en su línea.
- [ ] Retro final escrita, con las conclusiones del piloto SDD.
- [ ] Demo final hecha.

Criterios: [`docs/court-connect/evaluacion.md`](../../docs/court-connect/evaluacion.md).
