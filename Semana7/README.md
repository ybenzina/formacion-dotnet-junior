# Semana 7 — Acceso a datos (ADO.NET + EF Core + Caching)

## Objetivos
- Diseñar el modelo de datos (Users, Events, RSVP, Locations).
- Implementar Domain + Infrastructure con EF Core (DbContext, migraciones).
- Implementar patrón Repository (IEventRepository) y Ejemplo ADO.NET.
- Introducir caching (IMemoryCache) para listados frecuentes.
- Tests unitarios con EF InMemory.

## Ejercicios
- **Ejercicio1**: Crear esquema DB y entidades (Domain)
- **Ejercicio2**: Implementar EfEventRepository + migraciones
- **Ejercicio3**: Implementar caching en GetUpcomingEvents y tests
